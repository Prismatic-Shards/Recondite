**Recondite** adds elemental spellbooks that are able to found and crafted in the new structures. These spellbooks are able to be upgraded with resources like ink, which makes the spellbooks stronger and more powerful!

-------
## Features
- Several Themed Spellbooks (As of right now, 4)
- New Resources
- New Structures
- More to come!

## Notes
- There is a **required** [resource pack](https://modrinth.com/resourcepack/recondite-resource-pack) that needs to be downloaded with this datapack for some things too look correctly such as items and projectiles.
- This datapack is still under development and VERY MUCH a WIP so bugs should be expected. The existing spellbooks are not finished and should be expected to not be fully functional. Please report any bugs or issues you encounter, this lets us (mostly me) improve the datapack and make the player experience better.
- Recondite items do not show up in the creative menu. To get recondite item do `/loot give @s loot recondite:item/<item>`.
